HJ 프레젠테이션 리모컨 사용설명서
=====================================

[구성]
- remote_server.py : 노트북 프로그램 원본
- remote.html      : 폰 화면 (실행 파일 안에 함께 들어감)
- build_exe.bat    : 실행 파일(HJ_Remote.exe)을 만드는 배치 파일 (처음 한 번만)
- firewall_allow.bat  : 같은 와이파이 연결이 안 될 때 한 번 실행 (HJ_Remote.exe 와 같은 폴더에)
- requirements.txt : 필요한 부품 목록
- .github/workflows/build.yml : (선택) GitHub에서 실행 파일을 자동으로 만들 때 사용


1. 실행 파일 만들기 (처음 한 번만)
-------------------------------------
 1) python.org 에서 Python 3.12 를 설치합니다.
    설치 첫 화면에서 "Add python.exe to PATH" 에 반드시 체크하세요.
 2) 압축을 푼 폴더에서 build_exe.bat 을 더블클릭합니다. (몇 분 걸림)
 3) 완료되면 dist 폴더에 HJ_Remote.exe 가 생깁니다.
    이 파일만 원하는 곳(예: 바탕화면)으로 옮겨 쓰면 됩니다. Python은 지워도 됩니다.


2. 강의 때 쓰는 법
-------------------
 1) HJ_Remote.exe 를 실행합니다.
    - 처음 실행 때 윈도우 방화벽 창이 뜨면 [개인] 과 [공용] 네트워크 둘 다 체크하고 [허용]을 누르세요.
      (강의장 와이파이는 대개 '공용'으로 잡히므로 공용 체크가 중요합니다)
    - "PC 보호" 파란 창이 뜨면 [추가 정보] → [실행].
 2) 노트북 브라우저에 QR 코드 창이 열립니다.
 3) 폰 카메라로 QR 을 찍어 접속합니다.
 4) PowerPoint 에서 슬라이드쇼(F5)를 시작합니다. 폰 위쪽에 "3 / 25" 처럼 슬라이드 번호가 보이면 정상입니다.
 5) 끝낼 때는 검은 콘솔 창을 닫습니다.

 ※ 폰에서 Chrome 메뉴 → "홈 화면에 추가" 를 해 두면 앱처럼 열립니다.
   (단, 같은 와이파이 방식은 네트워크가 바뀌면 주소가 바뀌므로 그때그때 QR 을 찍는 편이 확실합니다)


3. 네트워크 고르기
-------------------
 [가장 확실함] LTE USB 동글
   동글을 노트북에 꽂고, 폰도 동글의 와이파이에 연결 → 왼쪽 QR(같은 와이파이로 연결) 사용.
   인터넷이 안 되어도 동작합니다.

 [X1 셀룰러]
   - 노트북 설정 → 네트워크 → 모바일 핫스팟을 켜고 폰을 거기에 연결 → 왼쪽 QR.
   - 핫스팟이 막힌 곳이면: 폰은 자체 데이터, 노트북은 셀룰러 → 오른쪽 QR(인터넷 중계).

 [강의장 공용 와이파이]
   - 먼저 왼쪽 QR 을 시도합니다.
   - 폰 화면이 계속 "다시 연결 중" 이면 와이파이가 기기끼리 통신을 막아 둔 것입니다.
     → 오른쪽 QR(인터넷 중계)을 쓰세요. 폰은 같은 와이파이든 자체 데이터든 상관없습니다.


 [잘 안 될 때]
 - 왼쪽 QR 이 폰에서 안 열림
   ① 폰이 노트북과 같은 와이파이에 연결되어 있는지 (폰 데이터가 아니라 와이파이)
   ② firewall_allow.bat 을 더블클릭 → [예] → 프로그램 다시 실행
   ③ 그래도 안 되면 그 와이파이가 기기끼리 통신을 막아 둔 것 → 오른쪽 QR 사용
 - 오른쪽 QR 에서 '노트북 응답 없음'
   노트북 QR 창의 '인터넷 중계로 연결' 아래 상태를 보세요.
   🔴 만 있으면 노트북이 있는 네트워크(회사망 등)가 중계 서버를 막고 있는 것입니다.
   → 노트북을 LTE 동글이나 셀룰러로 연결하면 대개 해결됩니다.
   중계 서버는 3곳에 동시에 연결을 시도하며, 하나라도 🟢 이면 동작합니다.

 인터넷 중계는 반응이 0.1~0.3초 정도 느릴 수 있습니다(특히 포인터). 가능하면 같은 와이파이 방식이 더 매끄럽습니다.


4. 인터넷 중계 준비 (한 번만)
-------------------------------
 인터넷 중계용 폰 화면은 인터넷에 올려 두어야 합니다.
 - remote.html 을 GitHub Pages 저장소에 올립니다.
   기본 설정 주소: https://coachhj.github.io/remote/remote.html
 - 다른 곳에 올렸다면 HJ_Remote.exe 옆에 생기는 hj_remote_config.json 의
   "relay_page_url" 값을 그 주소로 바꾸고 프로그램을 다시 실행하세요.


5. 버튼 설명
-------------
 - 이전 / 다음 : PowerPoint 슬라이드쇼를 직접 조작합니다(다른 창이 앞에 있어도 동작).
                 슬라이드쇼가 아닐 때는 ← / → 키를 보냅니다(PDF 등에서도 사용 가능).
 - 음량 − / 음소거 / + : 노트북 전체 음량. 한 번에 4%씩 (설정의 volume_step 으로 조절).
 - 재생/정지 : 윈도우 미디어 플레이어만 골라서 재생/정지합니다.
               (윈도우 11 '미디어 플레이어' 와 예전 'Windows Media Player' 모두 지원)
 - 레이저 : PowerPoint 레이저 포인터 켜기/끄기. 켜지면 버튼이 빨갛게 됩니다.
 - 가운데 : 마우스 포인터를 슬라이드쇼 화면 가운데로 옮깁니다. (레이저 켜고 먼저 누르면 편함)
 - 아래 넓은 칸 : 문지르면 포인터가 움직입니다. 클릭은 하지 않습니다(실수로 슬라이드가 넘어가지 않도록).
                  오른쪽 아래 − / + 로 감도 조절.


6. 보안
--------
 - 접속 주소에 비밀 열쇠(k=...)가 들어 있어, QR 을 찍은 폰만 조작할 수 있습니다.
 - 폰에서 보낼 수 있는 명령은 위 버튼 기능뿐입니다(파일 접근, 임의 입력 불가).
 - 열쇠를 바꾸고 싶으면 hj_remote_config.json 을 지우고 다시 실행하세요.
