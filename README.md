# HJ 프레젠테이션 리모컨

안드로이드 폰으로 윈도우 노트북의 PowerPoint를 조작하는 리모컨입니다.

- 슬라이드 이전/다음, 음량, 윈도우 미디어 플레이어 재생/정지, 레이저 포인터
- 같은 와이파이로 직접 연결하거나, 인터넷 중계로 연결

자세한 사용법은 `사용설명서.txt`를 보세요.

## 실행 파일 받기
[Actions](../../actions) 탭 → 가장 최근 `build-exe` 실행 → 아래 Artifacts의 **HJ_Remote** 를 내려받아 압축을 풀면 `HJ_Remote.exe` 가 있습니다.
(또는 이 저장소를 내려받아 `build_exe.bat` 실행)
